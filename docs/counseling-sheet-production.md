# カウンセリング票システム — 本番運用チェックリスト

クライアントの健康情報（要配慮個人情報）を扱うため、公開前に下記を必ず確認する。

## 1. デプロイ前に必須の環境変数（Vercel）

| 変数 | 用途 | 未設定時 |
|---|---|---|
| `ADMIN_PASSWORD` | 管理画面ログイン | **フォールバック値になり危険** → 必ず設定 |
| `BLOB_READ_WRITE_TOKEN` | データ保存先(Vercel Blob) | 保存不可 |
| `INTAKE_LINK_SECRET` | マイページURLの推測防止(HMAC鍵) | 開発用既定値でURLが推測可能に |
| `NEXT_PUBLIC_SITE_URL` | メール内リンクの絶対URL | mitoflow40.com にフォールバック |
| `RESEND_API_KEY` | 通知・確認メール | メール送信スキップ |
| `INTAKE_NOTIFY_EMAIL` | 管理者への受付通知先 | CONTACT_EMAIL にフォールバック |
| `CRON_SECRET` | 自動バックアップCronの認証 | Cronが弾かれる |

`.env.example` を参照。

## 2. できていること（実装済み）

- 受付フォーム `/counseling-sheet`（多段・全問診・ファイル・同意必須・noindex・ハニーポットでbot対策）
- 保存：Vercel Blob（推測不能パス）。**部分書き込み時は孤立ファイルを自動削除**
- 本人マイページ `/counseling-sheet/my/[clientId]`（HMAC鍵URL・見返し／追記）
- 受付確認メール（本人へマイページリンク）＋管理者通知メール
- 管理：クライアント一覧／詳細／全問診表示／CSV・JSONエクスポート
- **対応ステータス（未対応〜完了）＋担当メモ**
- **削除機能**（票単位／クライアント丸ごと＝本人の削除要求に対応）
- 解析レポート `/r/<token>` の紐付け
- **自動バックアップ**（Vercel Cron 毎日18:00 UTC → `intake/_backups/`）＋手動バックアップ
