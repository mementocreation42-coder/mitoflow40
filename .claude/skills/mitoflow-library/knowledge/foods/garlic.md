# にんにく（Garlic）

- URL: https://mitoflow40.com/foods/garlic
- 種類: 食べ物
- 分類: スパイス・ハーブ
- 一言: 解毒とエネルギーを支える香味野菜。

## 説明

にんにくは、独特の香りのもとになる硫黄化合物を豊富に含み、少量でも体に大きく働きかける香味野菜です。刻んだりつぶしたりすると生まれるアリシンという成分は、抗菌・抗酸化の作用を持ち、ビタミンB1と結びついて疲労回復を後押しするとされます。また、にんにくの硫黄成分は、体内の抗酸化・解毒の中心であるグルタチオンや、その材料となるアミノ酸システインの働きを支え、有害物質の処理や細胞を守る力を助けます。ビタミンB6も含み、アミノ酸や神経伝達物質の代謝にも役立ちます。40代の『巡り』と『解毒』、そして夏バテやストレスからの回復を、陰で支える名脇役です。有効成分のアリシンは、刻んでから少し置くと生まれやすく、加熱しすぎると失われやすいので、料理の仕上げに加えると香りと働きを活かせます。生は刺激が強く、胃腸の弱い方や空腹時は負担になりやすいため、加熱して少量から取り入れるのが安心です。少量で料理の風味を大きく引き立てるため、薄味でも満足感が得られ、減塩の助けにもなります。すりおろし・みじん切り・素揚げなど使い方の幅が広く、油と合わせると香り成分が移って料理全体がおいしくなります。毎日の料理に少しずつ加えるだけで、無理なく続けられる香味野菜です。

## ヒント
- 刻んで少し置くと有効成分アリシンが生まれやすい。
- 加熱しすぎず、仕上げに加えると香り成分を活かせる。
- 生は刺激が強いので、胃の弱い方は加熱して少量から。
