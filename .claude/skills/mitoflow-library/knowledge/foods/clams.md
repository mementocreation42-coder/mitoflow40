# あさり・しじみ（Clams）

- URL: https://mitoflow40.com/foods/clams
- 種類: 食べ物
- 分類: 魚介
- 一言: ビタミンB12と鉄の手軽な供給源。

## 説明

あさり・しじみは、神経の働きと赤血球づくりに欠かせないビタミンB12を、食材の中でもとくに多く含みます。ビタミンB12は主に動物性食品にしかなく、加齢で胃酸が減ると吸収が落ちるため、40代以降は意識して摂りたい栄養素。不足すると、貧血だけでなく、しびれ・もの忘れ・気分の落ち込み・朝のだるさといった神経のサインにもつながります。あさり・しじみはこのB12に加え、吸収の良い鉄や、免疫・味覚を支える亜鉛も補えるため、『貧血気味で疲れやすい』『朝すっきり起きられない』方にうれしい食材です。味噌汁や酒蒸しにすれば、汁に溶け出した鉄・B12・旨味成分まで余さず摂れて、無理なく続けられます。しじみに多いオルニチンは肝臓の働きを助けるとされ、冷凍すると旨味とともに増えるといわれるので、常備にも便利。砂抜きをしっかり行い、加熱して安全に楽しみましょう。貝類のうまみ成分には、肝臓の働きを助けたり疲労回復を後押ししたりするタウリンも含まれます。あさりの酒蒸し・しじみの味噌汁・ボンゴレなど、和洋問わず手軽な一品にしやすいのも魅力。冷凍貝を常備しておけば、忙しい日でもさっとビタミンB12と鉄を補える、便利で続けやすい食材です。

## ヒント
- 味噌汁・酒蒸しにして、溶け出した栄養を汁ごと摂る。
- 冷凍しじみは旨味とオルニチンが増えるとされ常備に便利。
- 鉄は植物性食品と組み合わせるより吸収されやすい。
