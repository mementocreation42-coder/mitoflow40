# レバー（Liver）

- URL: https://mitoflow40.com/foods/liver
- 種類: 食べ物
- 分類: 肉・卵
- 一言: 栄養の宝庫。少量で広くカバー。

## 説明

レバーは自然界でもっとも栄養密度が高い食材のひとつで、『天然のサプリメント』とも呼ばれます。吸収の良い鉄、神経と造血のビタミンB12、細胞づくりとメチレーションの葉酸、鉄の利用を助ける銅、エネルギー代謝のビタミンB2・ナイアシン、脳と肝臓を支えるコリン、そしてミトコンドリアの発電を支えるコエンザイムQ10まで、少量で驚くほど幅広い栄養を一度に補えます。40代の『なんとなく疲れる』『貧血気味で顔色が悪い』『階段で息が切れる』といった、複数の栄養不足が重なった状態を効率よく底上げできるのが魅力です。一方で、ビタミンAが非常に豊富なため、毎日たくさん食べると過剰摂取のリスクがあります。週1〜2回・少量にとどめるのが安心で、とくに妊娠中や妊娠の可能性がある方はビタミンA量に注意し、医師に相談してください。下処理で臭みを抜き、にんにくやしょうがと炒めると、においが和らいで食べやすくなります。鉄やビタミンB12が不足して起こる貧血は、息切れや動悸、強い疲労感、集中力の低下を招きますが、レバーはこれらをまとめて補える数少ない食材です。サプリメントに頼る前にまず食事から栄養を底上げしたい方にこそ向いており、体調や血液検査の数値を見ながら、自分に必要な頻度を見極めましょう。

## ヒント
- 週1〜2回・少量で十分。ビタミンAの摂りすぎを避けるため毎日は控える。
- 下処理で臭み抜きをし、にんにく・しょうがと炒めると食べやすい。
- 妊娠中・妊娠の可能性がある方はビタミンA量に注意し医師に相談を。
