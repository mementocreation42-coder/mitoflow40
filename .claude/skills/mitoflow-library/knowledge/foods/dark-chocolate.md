# ダークチョコレート（Dark Chocolate）

- URL: https://mitoflow40.com/foods/dark-chocolate
- 種類: 食べ物
- 分類: 果物・その他
- 一言: マグネシウム源になるご褒美。

## 説明

カカオ70%以上のダークチョコレートは、甘いお菓子のイメージとは異なり、マグネシウム・鉄・銅・食物繊維を含む『栄養になるご褒美』です。カカオに豊富なポリフェノール（カカオフラバノール）には抗酸化作用があり、血管をしなやかに保つ働きが研究で注目されています。マグネシウムは、ストレスや加齢で消耗しやすく、神経の興奮を鎮めて睡眠やメンタルの安定を支えるミネラル。『ストレスがたまるとチョコが欲しくなる』のは、体がマグネシウムを求めているサインとも言われます。砂糖たっぷりのミルクチョコの代わりに、カカオ分の高いダークチョコを少量取り入れれば、40代のストレス対策とマグネシウム補給を同時にかなえられます。ただし、あくまで嗜好品。カカオが高くてもカロリーや脂質はあり、食べすぎれば本末転倒です。1日2〜3かけ（10〜20g程度）を目安に、間食の置き換えとして楽しむのが、賢い付き合い方です。選ぶときは、原材料の最初にカカオマスが書かれ、砂糖が控えめなものを目安にすると失敗しにくいでしょう。少量をゆっくり味わえば満足感も得やすく、甘いもの欲求との上手な付き合いにも役立ちます。あくまで嗜好品として、量を決めて楽しむことが、健康的に続けるコツです。

## ヒント
- カカオ70%以上・砂糖少なめを選ぶ。
- 1日2〜3かけ（10〜20g）を目安に、間食の置き換えに。
- 甘いミルクチョコとは別物。糖質量に注意して選ぶ。
