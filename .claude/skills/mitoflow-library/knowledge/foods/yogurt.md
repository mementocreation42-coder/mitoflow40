# ヨーグルト（Yogurt）

- URL: https://mitoflow40.com/foods/yogurt
- 種類: 食べ物
- 分類: 大豆・発酵食品
- 一言: 腸を整える発酵タンパク。

## 説明

ヨーグルトは、タンパク質とビタミンB2・B12を含みながら、乳酸菌やビフィズス菌といった善玉菌で腸内環境を整えられる発酵食品です。腸は『第二の脳』とも呼ばれ、免疫細胞の多くが集まり、気分を左右するセロトニンづくりにも関わる重要な臓器。腸内のバランスが整うと、便通だけでなく、免疫力やメンタルの安定にも良い影響が期待できます。ヨーグルトにはセロトニンや睡眠ホルモン・メラトニンの材料になるトリプトファンも含まれ、睡眠の質を支える面でも役立ちます。40代の『腸の調子が不安定』『眠りが浅い』といった悩みに、手軽に習慣化できる食材です。砂糖の多い加糖タイプは血糖を上げやすいので、無糖を選び、はちみつや果物で甘みを足すのがおすすめ。オリゴ糖や食物繊維の多いバナナ・オーツと合わせると善玉菌が育ちやすくなります。高タンパクのギリシャヨーグルトは間食にも好適。腸内細菌の構成は人それぞれなので、自分の体に合う菌や商品を試しながら見つけましょう。腸内の菌のバランスは毎日続けることで整いやすくなるため、まずは2〜3週間ほど同じ商品を試して、お腹の調子や便通の変化を観察するのがおすすめです。手軽に続けられる発酵食品として、朝食や間食に取り入れてみてください。

## ヒント
- 無糖タイプを選び、はちみつや果物で甘みを足すと血糖にやさしい。
- オリゴ糖や食物繊維（バナナ・オーツ）と合わせると善玉菌が育ちやすい。
- 高タンパクのギリシャヨーグルトは間食にも向く。
