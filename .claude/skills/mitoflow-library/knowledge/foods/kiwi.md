# キウイ（Kiwi）

- URL: https://mitoflow40.com/foods/kiwi
- 種類: 食べ物
- 分類: 果物・その他
- 一言: ビタミンCと食物繊維の朝の果物。

## 説明

キウイは、抗酸化の代表選手ビタミンCが非常に豊富で、1個食べるだけで一日の目安量をしっかり補える果物です。ビタミンCは、体のサビを防ぐ抗酸化作用に加え、肌のハリを保つコラーゲンの生成、植物性食品の鉄の吸収を高める働き、ストレスや免疫への対応など、40代にうれしい役割を幅広く担います。加えて、腸の動きを助ける食物繊維と、細胞づくりや造血に関わる葉酸も含み、肌・免疫・腸活をまとめてケアできるのが魅力。とくにグリーンキウイは食物繊維が多く便通の後押しに、ゴールドキウイはビタミンCがさらに豊富です。ビタミンCは熱に弱いので、生でそのまま食べるのが効率的。朝に1個取り入れると、ビタミンCと食物繊維で一日のスタートを支えてくれます。鉄を含む食事と一緒に摂れば鉄の吸収が高まり、ヨーグルトに添えれば腸活の相乗効果も狙えます。甘みと酸味のバランスがよく、手軽で続けやすいデザートです。果物の中では糖質が比較的おだやかで、ビタミンや食物繊維をしっかり摂れるのも利点です。皮をむいて切るだけ、半分に切ってスプーンですくうだけと手軽で、忙しい朝でも続けやすいのが魅力。ヨーグルトやサラダに加えれば彩りも栄養もアップし、毎日のビタミンC補給にぴったりです。

## ヒント
- 朝に1個食べると、ビタミンCと食物繊維で一日のスタートを支える。
- 鉄を含む食事と合わせると鉄の吸収が高まる。
- ゴールドキウイはビタミンCがさらに多い。
