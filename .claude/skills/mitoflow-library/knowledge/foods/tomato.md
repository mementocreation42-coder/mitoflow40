# トマト（Tomato）

- URL: https://mitoflow40.com/foods/tomato
- 種類: 食べ物
- 分類: 野菜
- 一言: リコピンで体のサビを防ぐ赤い抗酸化野菜。

## 説明

トマトは、赤い色のもとになるリコピンという抗酸化成分で知られる野菜です。リコピンはβ-カロテンの仲間で、強い抗酸化力を持ち、体のサビ＝酸化ストレスから細胞を守る働きが注目されています。さらに、抗酸化とコラーゲン生成に関わるビタミンC、腸を整える食物繊維、そして体内の抗酸化の要であるグルタチオンの働きも後押しします。40代の老化を進める三本柱『酸化・糖化・炎症』のうち、とくに酸化ストレスへのケアに役立つ食材です。リコピンは脂溶性のため、生のままよりも油と一緒に加熱した方が吸収が大きく高まります。トマトソースやスープ、オリーブオイルをかけたサラダなど、油と合わせる食べ方が理にかなっています。加熱でかさが減るので量も摂りやすく、うま味成分グルタミン酸が豊富なため、少ない調味料でも料理に深いコクを与え、減塩の助けにもなります。生のトマトはみずみずしく水分補給にもなり、加熱したトマトはリコピンを効率よく補える——調理を使い分けると飽きずに続けられます。トマトジュースや缶詰のトマトも手軽なリコピン源になり、忙しい日でも一品に加えやすいのが魅力です。サラダ・煮込み・スープ・ソースと幅広く使え、彩りも食卓を明るくしてくれる、毎日続けやすい抗酸化野菜です。

## ヒント
- リコピンは脂溶性。オリーブオイルと一緒に加熱すると吸収が大きく高まる。
- 加熱するとかさが減って量を摂りやすく、うま味で減塩の助けにもなる。
- トマトジュースや缶詰のトマトも手軽なリコピン源になる。
