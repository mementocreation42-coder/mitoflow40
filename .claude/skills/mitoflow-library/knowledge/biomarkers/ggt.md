# γ-GTP（γ-GTP）

- URL: https://mitoflow40.com/biomarkers/ggt
- 種類: 血液検査
- 分類: 肝機能
- 一言: アルコールと解毒負荷のバロメーター

## 解説

γ-GTP（ガンマGTP）は、肝臓・腎臓・膵臓などに多く存在する酵素で、健診ではアルコールや解毒の負荷を映すバロメーターとしてよく知られています。とくに肝臓や胆管の細胞が刺激を受けると血液中に出てくるため、お酒をよく飲む人や、肝臓に負担がかかっている人で上昇しやすい指標です。「飲みすぎると上がる数値」というイメージを持っている方も多いでしょう。

ただ、γ-GTPの意味はアルコールだけにとどまりません。この酵素は、体内の最重要の抗酸化物質であるグルタチオン（GSH）の生成や運搬に関わっています。そのため、薬の服用、脂肪肝、そして酸化ストレスが強い状態など、解毒や抗酸化の負荷が高まる場面でも変動します。いわばγ-GTPは、肝臓がどれだけ「解毒・抗酸化のための残業」をしているかを映す窓ともいえます。

実用面で便利なのは、アルコールの影響を確かめやすいことです。飲酒が原因で上がっているγ-GTPは、お酒をやめると比較的すみやかに下がってきます。逆に、2〜4週間の禁酒でも下がってこない場合は、脂肪肝やその他の肝胆道の問題を念頭に、γ-GTP単独でなくAST・ALT・ALPと合わせて評価する必要があります。グルタチオンを支えるNAC・セレン・ビタミンCなどのケアで改善することもあり、生活と栄養の両面から見直したい指標です。
