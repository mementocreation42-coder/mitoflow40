# 酸性・アルカリ性とは｜体のpHと「アルカリ性食品」の誤解

- URL: https://mitoflow40.com/acid-alkaline
- 分類: しくみ ／ 血液pHの調節・アルカリ性食品の誤解
- 概要: 酸性・アルカリ性（pH）とは何か。血液のpHは体が厳密に保っており、食べ物で体が酸性・アルカリ性に「傾く」ことは基本的にありません。アルカリ性食品・アルカリイオン水・酸性体質といった話のどこが本当で、どこが誤解なのかを、生化学に基づいて出典つきで整理します。

## 本文

ACID &amp; ALKALINE

「アルカリ性食品で体質を改善」「酸性体質は病気のもと」——よく聞く話ですが、ここには大きな誤解があります。じつは血液の酸性・アルカリ性（pH）は、体がきわめて厳密に保っているもの。仕組みを知ると、何が本当で、何がマーケティングなのかが見えてきます。

### pH（ペーハー）とは

pHとは、液体が酸性か・アルカリ性かを0〜14の数字で表したもの。7が中性で、それより小さいと酸性、大きいとアルカリ性です。レモンやお酢は酸性、重曹や石けん水はアルカリ性、というイメージです。 ここで大事なのは、体の場所ごとに最適なpHが決まっていること。たとえば胃の中は強い酸性（pH1〜2前後）で、食べ物を消化し、菌を殺すために、わざと酸性になっています。一方で血液は弱アルカリ性（pH7.35〜7.45）という、とても狭い範囲に保たれています。

### 血液のpHは、食べ物では変わらない

ここが最大のポイントです。血液のpHは、食事によって酸性やアルカリ性に「傾く」ことは基本的にありません。体には、pHを一定に保つための強力な仕組みが何重にも備わっているからです。 もし血液のpHが7.35〜7.45の範囲を大きく外れると、それは食べ物のせいではなく、重い病気のサイン（重症の腎臓病・肺の病気・糖尿病の急変など）です。健康な体では、何を食べても血液pHはこの範囲にきっちり戻されます。「酸性食品を食べたから血液が酸性になる」という考え方そのものが、成り立たないのです。

### 体がpHを守る3つの仕組み

速さの違う3つの調整役が、いつも血液pHを一定に保っています。

### 「アルカリ性食品」「酸性体質」をどう見るか

「酸性食品・アルカリ性食品」という分類は、もともと食品を燃やしたあとに残る灰が酸性かアルカリ性かという、体内とは別の話から来ています。これが「体を酸性／アルカリ性にする」と拡大解釈され、広まりました。 食事は、せいぜい尿のpHを多少変える程度。これは腎臓が余分な酸やアルカリを捨てている、体が正常に働いている証拠であって、「体質が変わった」わけではありません。「酸性体質」という医学的な体質区分も存在しません。 同じく「アルカリ性食品でがんが治る／予防できる」という主張には、確かな科学的根拠はありません。アルカリイオン水も、胃に入れば強い胃酸ですぐ中和されます。煽る情報ほど、出典を確かめる価値があります。

### では「野菜中心がいい」は嘘？──いいえ、理由が違うだけ

ややこしいのは、「野菜・果物を多く、肉や加工食品をほどほどに」という食事は、実際に体にいいということ。アルカリ性食品を勧める人の結論は、しばしば正しい方向を向いています。 ただし効く理由は「アルカリ性だから」ではありません。野菜・果物が良いのは、カリウム・マグネシウム・食物繊維・ポリフェノールが豊富で、塩分や過剰なたんぱく質が控えめだから。腎臓や骨への負担、血圧の面でも有利です。つまり正しい食事の理由を、正しい仕組みで理解することが、振り回されないコツです。

### まとめ：pHは「整えるもの」ではなく「保たれているもの」

血液のpHは、あなたが意識しなくても、肺と腎臓と緩衝系が休まず一定に保ってくれています。だから「体をアルカリ性にしよう」とする必要はありません。やるべきは、その精巧な仕組みが働きやすいように、野菜を多めに、塩分ひかえめに、水分と睡眠を整えること。結論は地味ですが、それが事実です。

- name: 肺（呼吸） ／ en: LUNGS ／ body: 二酸化炭素（CO₂）は水に溶けると酸性に働きます。体は呼吸の速さ・深さを変えてCO₂の量を調整し、数分単位でpHを整えます。
- name: 腎臓（尿） ／ en: KIDNEYS ／ body: 余った酸やアルカリを尿として捨て、必要な重炭酸を回収します。いちばんゆっくりですが、強力で持続的な調整役。「尿のpH」が食事で変わるのは、まさにこの働きの結果です。
