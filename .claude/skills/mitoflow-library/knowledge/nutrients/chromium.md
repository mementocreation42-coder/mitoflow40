# クロム（CHROMIUM）

- URL: https://mitoflow40.com/nutrients/chromium
- 種類: 栄養素
- 分類: ミネラル
- 一言: インスリンの効きを下支えする微量ミネラル

## 解説

クロム(三価クロム)は、ごく微量で働くミネラルで、インスリンが細胞にブドウ糖を取り込ませる場面を助けると考えられています。クロモデュリンという小さなタンパク質がインスリン受容体の信号を増幅する、というのが想定されているしくみで、不足すると血糖が安定しにくくなる可能性があります。

ただし、根拠の確かさには注意が必要です。クロムのサプリが血糖やHbA1cを改善するかどうかは研究結果が分かれており、もともと不足している人や糖代謝が乱れている人では効果が見られる一方、健康な人では差が出ないことが多いとされています。「摂れば血糖が下がる」と単純化しない方が誠実です。

食事からのクロムは精製された糖質や砂糖で排泄が増えるため、精製炭水化物が多い食生活ほど失われやすい面があります。まずは食事全体(食物繊維・タンパク質・マグネシウム)を整えたうえで、全粒穀物やブロッコリーなど自然な食品から少しずつ補う、という位置づけがちょうどよい栄養素です。

## deficiencySigns
- 食後の血糖が安定しない
- 甘いものへの渇望
- 食後の眠気・だるさ
- 体重が増えやすい

## 食べ物
- ブロッコリー
- 全粒穀物
- 肉・レバー
- 卵
- ビール酵母
- ナッツ
