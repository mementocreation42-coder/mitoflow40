# パントテン酸 (B5)（PANTOTHENIC ACID）

- URL: https://mitoflow40.com/nutrients/b5
- 種類: 栄養素
- 分類: ビタミンB群
- 一言: アセチルCoAをつくり、TCA回路の入口を開ける補酵素

## 解説

パントテン酸(ビタミンB5)は、補酵素A(CoA)の材料になるビタミンです。糖も脂質もタンパク質も、ミトコンドリアでエネルギーになるときは一度「アセチルCoA」という形に姿を変えてからTCA回路に入ります。B5はその入口をつくる役目で、足りないと燃料はあるのに回路に入れない、という状態を招きます。

もうひとつの大きな役割が副腎です。コルチゾールをはじめとするステロイドホルモンや、脂肪酸・コレステロール・アセチルコリンの合成にもCoAが使われるため、ストレスが続く時期ほど消費が増えます。「抗ストレスビタミン」と呼ばれる理由はここにあります。

ギリシャ語で「どこにでもある」を意味する名のとおり、多くの食品に含まれ、単独の欠乏はまれです。ただし精製・加工の過程で失われやすく、加工食品中心の食事やアルコール、慢性的なストレスで相対的に不足することがあります。B群はチームで働くので、B5だけを大量に摂るより、まとめて底上げする考え方が向いています。

## deficiencySigns
- 疲れやすい・エネルギーが続かない
- ストレスに弱い・回復が遅い
- 足の裏の灼熱感・しびれ(重度)
- 頭痛・眠りの浅さ
