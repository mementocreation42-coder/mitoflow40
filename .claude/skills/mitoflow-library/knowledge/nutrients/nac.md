# NAC（N-ACETYLCYSTEINE）

- URL: https://mitoflow40.com/nutrients/nac
- 種類: 栄養素
- 分類: その他
- 一言: グルタチオンの材料になる解毒サポーター

## 解説

NAC(N-アセチルシステイン)は、アミノ酸システインを体内で利用しやすくした形で、体内最強の抗酸化物質グルタチオンの直接の材料になります。グルタチオンそのものは経口では吸収されにくいため、NACで材料を補い、体内での合成を後押しするのが効率的なアプローチです。

グルタチオンを増やすことで、解毒(GSTの働き)や抗酸化、ミトコンドリアの保護を底上げします。加えて、NAC自体に粘液を溶かして気道をきれいにする作用があり、呼吸器のケアにも古くから使われてきました。

GSTの働きが弱く解毒力に不安がある人、化学物質に敏感な人、酸化ストレスを下げたい人にとって、グルタチオン底上げの現実的な選択肢です。サプリで補う場合は、グリシンやグルタミンなど他の材料と組み合わせると効果的です。

## deficiencySigns
- (材料栄養素のため明確な欠乏症はないが)
- グルタチオン不足のサインに準じる
- 解毒力の低下・化学物質過敏
- 酸化ストレスの蓄積

## 食べ物
- (食品では高ヒスチジン・含硫アミノ酸食品)
- 鶏肉・卵
- にんにく・玉ねぎ
- ※主にサプリで補う
