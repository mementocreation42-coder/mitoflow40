# コリン（CHOLINE）

- URL: https://mitoflow40.com/nutrients/choline
- 種類: 栄養素
- 分類: その他
- 一言: 細胞膜・肝臓・記憶を支える準ビタミン

## 解説

コリンは、ビタミンに準じる必須栄養素で、3つの重要な役割を持ちます。1つ目は、細胞膜の主成分ホスファチジルコリンの材料になること。2つ目は、記憶や筋肉の収縮に関わる神経伝達物質アセチルコリンの材料になること。3つ目は、メチレーション回路でメチル基を供給することです。

特に肝臓では、PEMTという酵素がコリン(ホスファチジルコリン)を内製していますが、それだけでは足りず食事からの補給が必要です。コリンが不足すると、肝臓に脂肪が溜まる脂肪肝や、脂質の運搬・消化の不調が起こりやすくなります。

PEMTの働きはエストロゲンで高まるため、閉経後の女性や男性はコリン需要が高まります。卵を避ける食生活では不足しがちで、記憶力の低下・脂肪肝・筋肉の回復の遅れの背景になることがあります。

## deficiencySigns
- 脂肪肝・肝機能の乱れ
- 記憶力・集中力の低下
- 筋肉痛・回復の遅れ
- 疲労感

## 食べ物
- 卵黄
- レバー
- 大豆・豆腐
- 鶏肉
- 牛肉
