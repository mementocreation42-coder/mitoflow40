# グリシン（GLYCINE）

- URL: https://mitoflow40.com/nutrients/glycine
- 種類: 栄養素
- 分類: タンパク質・アミノ酸
- 一言: 睡眠・コラーゲン・解毒を支える最小のアミノ酸

## 解説

グリシンは最も構造のシンプルなアミノ酸ですが、役割は多彩です。コラーゲンの約3分の1を占める主要成分で、皮膚・関節・血管・骨の土台になります。また、抑制性の神経伝達物質として働き、深部体温を下げて寝つきと睡眠の質を高めることが知られています。

さらにグリシンは、体内最強の抗酸化物質グルタチオンを構成する3つのアミノ酸のひとつ。GSTによる解毒や抗酸化の底上げに関わります。体内でも合成されますが、コラーゲンやグルタチオンの需要が高まると不足しがちな「条件的必須アミノ酸」です。

現代の食事は赤身肉中心でメチオニンに偏りやすく、皮や骨・結合組織に多いグリシンが相対的に不足しやすいと指摘されます。ボーンブロスやゼラチンで補うのが現実的です。

## deficiencySigns
- 寝つき・睡眠の質の低下
- 肌・関節の衰え
- 解毒力の低下
- 回復の遅れ

## 食べ物
- ボーンブロス・煮こごり
- ゼラチン・コラーゲン
- 鶏皮・手羽
- 魚の皮
