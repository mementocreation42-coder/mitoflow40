# ヨウ素（IODINE）

- URL: https://mitoflow40.com/nutrients/iodine
- 種類: 栄養素
- 分類: ミネラル
- 一言: 甲状腺ホルモンの材料。日本では「不足」より「過剰」に注意

## 解説

ヨウ素は、甲状腺ホルモン(T4・T3)を構成するミネラルです。甲状腺ホルモンは全身の細胞に「代謝の速度」を指示するホルモンで、体温・エネルギー産生・心拍・脳の働きまで調整します。ミトコンドリアの数や活性もこのホルモンの影響を受けるため、ヨウ素は「エネルギーの司令部の材料」と言えます。

世界的にはヨウ素不足が甲状腺腫や発達への影響の原因として大きな問題ですが、日本は事情が違います。昆布・わかめ・のりなどの海藻を日常的に食べるため、日本人の摂取量は世界でも際立って多く、不足はまれです。むしろ昆布だしや昆布の常食による摂りすぎで甲状腺の働きが乱れることがあり、「不足より過剰」を意識した方がよい国です。

一方で、海藻や魚をほとんど食べない人、妊娠・授乳期、極端な食事制限をしている人では不足が起こりえます。甲状腺の数値(TSH・FT4・FT3)が気になるときは、ヨウ素だけでなく、ホルモンを活性型に変えるセレン、材料になる鉄・亜鉛・タンパク質も合わせて見るのが読み解きの基本です。

## deficiencySigns
- 甲状腺の腫れ
- 疲れ・冷え・代謝の低下(不足でも過剰でも)
- 体重が増えやすい
- 妊娠期の胎児の発達への影響

## 食べ物
- 昆布(少量でよい)
- わかめ
- のり
- 魚介類
- 卵
