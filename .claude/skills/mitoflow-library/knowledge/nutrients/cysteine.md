# システイン（CYSTEINE）

- URL: https://mitoflow40.com/nutrients/cysteine
- 種類: 栄養素
- 分類: タンパク質・アミノ酸
- 一言: グルタチオン合成の鍵を握る含硫アミノ酸

## 解説

システインは硫黄を含むアミノ酸で、体内最強の抗酸化物質グルタチオンを作る際の「律速段階（最も足りなくなりやすい材料）」を担います。グルタチオンの生産量はシステインの供給量に大きく左右されるため、解毒力・抗酸化力を支える鍵の栄養素です。

GSTやGPXといった解毒・抗酸化酵素はグルタチオンを使って働くため、システインが不足するとミトコンドリアを守る抗酸化システム全体が弱まります。化学物質に敏感・二日酔いがひどい・酸化ストレスが気になる人にとって重要です。

システインは体内でメチオニンからも作られますが、需要が高いときは食事やサプリでの補給が有効です。吸収しやすい形が、サプリでおなじみのNAC（N-アセチルシステイン）です。

## deficiencySigns
- 解毒力の低下・化学物質過敏
- 二日酔いがひどい
- 酸化ストレスの蓄積
- 疲労・回復の遅れ

## 食べ物
- 肉・魚
- 卵
- にんにく・玉ねぎ
- 乳製品
- ※サプリはNAC
