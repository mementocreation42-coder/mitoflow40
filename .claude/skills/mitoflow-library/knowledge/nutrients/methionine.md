# メチオニン（METHIONINE）

- URL: https://mitoflow40.com/nutrients/methionine
- 種類: 栄養素
- 分類: タンパク質・アミノ酸
- 一言: メチレーションの起点、含硫アミノ酸の代表

## 解説

メチオニンは体内で作れない必須アミノ酸で、メチレーション回路の出発点となる重要な存在です。メチオニンはSAMe（体内のメチル基供与体）に変換され、解毒・神経伝達物質の合成・DNAや遺伝子発現の調整など、全身の反応にメチル基を供給します。

メチル基を渡し終えたメチオニンは「ホモシステイン」に変化します。このホモシステインは、葉酸・B12（MTHFR経由）やB6によって再びメチオニンや無害な物質に作り替えられます。この処理が滞ると、血管を傷つけるホモシステインが蓄積するため、メチオニンの代謝はMTHFRや血液検査のホモシステイン値と直結します。

含硫アミノ酸として、抗酸化物質グルタチオンの材料経路にもつながります。良質なタンパク質に広く含まれますが、葉酸・B12・B6が揃って初めて安全に回ります。

## deficiencySigns
- （通常の食事では不足しにくい）
- 極端な菜食での不足
- ホモシステイン代謝の乱れ
